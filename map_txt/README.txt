Interactive map geometry for allaclone (Brewall-format .txt map files).

These zone files are vendored in-repo for deploy. Named by zone short name:
<short>.txt for the map lines, <short>_1.txt for place labels, <short>_2.txt
etc. for extra layers. Filename case does not matter (Qeynos_1.txt and
qeynos_1.txt both work).

Source: Brewall map packs at https://www.eqmaps.info/eq-map-files/
(Zeal's zone_map_src/map_files is a convenient local copy of the same format.)

Zones without a file here simply don't show an interactive map on the zone page.

Credit: Brewall (eqmaps.info); label layers may come from Project Miragul.
